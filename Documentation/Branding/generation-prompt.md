# OceanKit icon concept provenance

The selected concept was generated on October 4, 2026 with the built-in imagegen tool and `transparent_background: true`. It is preserved unchanged as `ocean-o-concept.png` at 1254 × 1254 pixels. No reference images were supplied.

## Original prompt

```text
Use case: logo-brand. Asset type: exploratory repository icon for OceanKit, a MATLAB oceanography software ecosystem encompassing ocean models, numerical tools and scientific data interfaces. Create one refined, minimal logo mark only, with no text. Primary request: a bold circular capital O with one broad flowing ocean wave inside its open center. The O is a thick deep navy ring; a simple sea teal wave occupies the lower part of its interior. The upper inner negative space is generous and open. One smooth shallow crest, no breaking surf, no splashes, no tiny details. Keep the wave integrated within the circular silhouette with deliberate clear negative-space gaps so it is readable at favicon size. Flat geometric graphic, crisp clean edges, restrained scientific software identity, strong optical balance, designed to be reproduced as simple vector paths. The silhouette must work as one-color artwork. Center one large mark occupying approximately 70 percent of square canvas. Transparent background, no backdrop. Navy and teal only. No typography, no shadows, no gradient, no dimensional rendering, no mockup, no decorative frame, no code symbols, no boats, no tools.
```

## Production artwork

The generated concept is an exploration. The production mark is an editable geometric SVG approximation: a circular navy ring and one teal wave path. The colors are flat, and a transparent gap separates the wave from the ring so the monochrome version retains both shapes. The small icon simplifies the wave and expands the gap. The full icons add a pale square or rounded square background for consistent browser and shortcut display.

Wordmarks use Avenir Next Medium, converted to paths by `export-assets.mjs`. The export script and asset organization follow the [WaveVortexModel branding idiom](https://github.com/JeffreyEarly/wave-vortex-model/tree/main/Documentation/Branding); no WaveVortexModel artwork appears in the OceanKit mark. The wordmark and social-card SVGs have no runtime font dependency.
