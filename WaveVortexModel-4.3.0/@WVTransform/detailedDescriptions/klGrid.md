Return the barotropic spectral-coordinate arrays.

`[K,L] = wvt.klGrid` returns angular wavenumbers in radians per meter with shape `[1 Nkl]`.

```matlab
[K,L] = wvt.klGrid;
```

- Declaration: [K,L] = klGrid()
- Returns K: x-direction angular wavenumber array in radians per meter
- Returns L: y-direction angular wavenumber array in radians per meter
