# Frozen mixed-product numerical controls

`wvm-cal-constant-17-products.json` contains six numerical controls from the WVM `cal-constant-17--fixed` study case. It contains sampled factors, complex prescribed projection duals, signed coefficient systems, positive reference norms, and expected product errors. Tests require only InternalModes and this JSON; no WVM classes or physical source formulas are included.

The controls cover wave–wave, boundary–wave, APV–boundary, and boundary–boundary inputs, with wave, mean-density-anomaly, and inertial outputs. Each control fixes its original two scientific input columns, preserving labels, ordinals, frequency signs, and provenance. Retained outputs use the first three original mode ordinals, including both frequency signs. Fixed mean/inertial outputs preserve their independent coordinates. These are individual numerical controls; they do not redefine the model's requested mode counts. Zero products and signed endpoint cancellation have additional executable controls in `IMProductAssessmentPlanTests`.

The full frozen case was regenerated with the WVM study's pinned scientific provider, `InternalModes-2.0.0-beta.1`, using `configureStudyPath` against the preserved `wvm400-oceankit` workspace. The new numerical inventory provider was placed last on the MATLAB path. A fresh MATLAB process ran outside the provider checkout so the scientific basis came from the pinned package. The WVM authoring revision is recorded in the fixture. The source study links are [issue #400](https://github.com/JeffreyEarly/wave-vortex-model/issues/400), [study PR #402](https://github.com/JeffreyEarly/wave-vortex-model/pull/402), and [advisory PR #405](https://github.com/JeffreyEarly/wave-vortex-model/pull/405).
